ProjectsManagerPlus é uma extensão para a IDE do Delphi (Open Tools API) que aprimora o Project Manager padrão permitindo a criação de unidades, pastas físicas e manipulação em lote.

## Where to start

- [Introduction](introduction.md)
- [Quickstart](getting-started/quickstart.md)
- [Architecture](architecture/overview.md)
- [API](reference/api.md)
- [Tests](tests/overview.md)

## Scope

- **Covers:** Adição de novas units em subdiretórios específicos, criação de pastas físicas e adição/remoção em lote de arquivos via menu de contexto no Project Manager.
- **Does not cover:** Processamento em lote de arquivos `.dfm` ou novos formatos, mudanças substanciais na UI da IDE ou alteração na forma de registrar Wizards.
